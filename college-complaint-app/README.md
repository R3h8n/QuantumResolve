# CampusCare - Cloud-Based College Complaint & Maintenance System

## Project Overview
CampusCare is a responsive React.js frontend system for reporting, managing, and tracking maintenance complaints across college facilities (Electrical, Wi-Fi, Classrooms, Hostels, Library, Cleanliness, etc.). Built for BTech CSE Capstone demonstration with full mock state persistence and role-based access.

## Technologies Used
- **React.js & Vite** - Modern frontend compilation
- **Tailwind CSS** - Utility-first modern UI styling
- **React Router DOM v6** - Dynamic role-based client-side routing
- **Lucide React** - Vector iconography
- **Recharts** - Interactive data analytics charts
- **Axios** - Prepared REST API HTTP client
