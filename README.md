# QuantumResolve: Cloud-Based College Complaint & Maintenance Management System

A full-stack role-based campus facility and complaint management platform built with **React.js, Vite, Tailwind CSS, Node.js, Express, and SQLite**.

## Key Features
- **Student Portal:** File categorized complaints with priority levels, view real-time status badges, and track an audited progress timeline.
- **Admin Portal:** Master complaint dashboard, department assignment, priority overrides, and live **Recharts** analytics (Bar & Pie charts).
- **Department Staff Portal:** Dedicated work order queues to log technical repair notes, set estimated resolution dates, and resolve tickets.
